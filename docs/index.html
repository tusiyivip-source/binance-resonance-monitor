零轴配对报警
独立控制零轴配对提醒。上方搜索、方向和靠近程度仅筛选页面，不修改后台报警条件。

对应需求：≥3 个级别多头排列 → 基准级别回踩后上穿 MA7/EMA7 → 确认级别同步上穿 → 最大级别不跌破均线。

级别组合（基准 → 确认 → 最大） 三者不必相邻，例如 3分 → 15分 → 2时
穷举模式 = 自动扫描「基准 + 它的下一档 + 任意更大级别」的全部组合，信号量会大很多。
缠论背驰过滤 确认级别「将要出现背驰笔」→ 判定上涨衰竭，拦下该信号
—
判定口径：包含处理 → 分型 → 标准笔 → MACD 红柱面积对比。 当前这一笔还没走完，但价格已越过前一同向笔的极值、而累计 MACD 面积反而更小 → 视为「将要出现背驰笔」。
实测（60 标的 / 24 小时）：15分 处于该状态的时间仅占 2.76%，却拦掉了 17.9% 的信号 —— 说明信号恰好高度聚集在顶部区域。
「面积衰减阈值」越小越严格（1.0 = 只要变小就判定）；「最小幅度比」用于避免把刚起步的短笔误判成背驰。
回踩成笔链（笔延续级别） 回调必须深到让中间的每个级别都成笔
—
只让最小级别成笔的回调是浅回调，撑不起大级别的延续。要算作 30分 笔延续， 必须让 5分、10分、15分全部成笔（即从基准级别到确认级别之间、不含确认级别的所有级别）：
· 5m>30m>3h → 要求 5m / 10m / 15m 成笔
· 3m>15m>2h → 要求 3m / 5m / 10m 成笔
· 2m>10m>1h → 要求 2m / 3m / 5m 成笔
判定方式：某级别的「最近一个完成的向下笔」的底，必须落在基准级别回调起点之后。
实测（140 条信号）：只要求成笔保留 25.0%；再加上「都站上 MA7」保留 17.9%。 卡住的总是紧挨确认级别的那一级（30分组卡 10分、10分组卡 5分）——它的笔最长、最难成。

形态提醒（独立） 双阴不破均线 / 双阳不穿破均线
级别：15分 / 30分 / 1时 / 2时 / 3时，第二根K线一收盘立刻提醒，不等其他条件。
双阴不破（多）：连续两根阴K，收盘都没跌破 MA7 与 EMA7（影线可插破）—— 上涨途中浅回调、抛压枯竭。
双阳不穿（空）：连续两根阳K，收盘都没涨破 MA7 与 EMA7（影线可刺破）—— 下跌途中浅反弹、买盘枯竭。
这一组提醒不依赖共振组合，也不依赖下面的两阶段盯盘，是独立的形态信号。
成交额下限：24H 成交额低于此值不提醒（默认 400 万 USDT）—— 小成交额的币容易凑出假形态，且滑点大不好成交。填 0 表示不限制。
两阶段盯盘（预备 → 触发） 大级别先预备，最小级别首次站上才报警
阶段一：大级别（1h / 2h / 3h / 4h）首次出现「连续 N 根阴K收盘不破 MA7/EMA7」→ 进入预备名单，此时不报警。
阶段二：之后盯最小级别，先收盘跌破 MA7 与 EMA7，再首次收盘重新站上两条线 → ★ 立即报警。
次级别是否够笔、大级别内中间级别是否够笔、临近级别是否上穿 —— 都作为参考信息带在报警里，不拦截信号。
级别对应表（用户确认）：2m→10m→1h、3m→15m→2h、5m→30m→3h。
回踩形态 基准级别的回踩长什么样才算数
两根阴K不破均线：连续 N 根K线都是阴线，且每根的收盘价都没有跌破 MA7、也没有跌破 EMA7 —— 影线允许插破。随后当前K线收盘同时站上 MA7 与 EMA7 即触发。
含义：上涨途中极浅的回调，连收盘都没能把价格压到均线下方，说明抛压枯竭（跌无可跌）。
注意：这种形态下价格压根没离开均线上方，所以不存在「上穿 MA7」事件， 触发条件改用「收盘同时站上两条均线」。选另一种判定方式时行为与原来一致。
