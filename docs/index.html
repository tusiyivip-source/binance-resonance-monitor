02报警逻辑

级别分组是固定三元组，不是相邻级别。

组合基准级别确认级别最大级别
3m > 15m > 2h3分15分2时
2m > 10m > 1h2分10分1时
5m > 30m > 3h5分30分3时

触发条件

① 基准级别回踩后突破

先回踩触及 MA7（回踩），随后收盘价上穿 MA7 与 EMA7，并站在均线上方。

② 确认级别同步上穿

确认级别在最近几根K线内也上穿 MA7 —— 也就是「临近级别也上穿均线」。

③ 最大级别不能跌破

最大级别收盘价需站在 EMA7/MA7 与 MA25 之上，且不处于空头排列。

④ 共振级别数 ≥ 3

14 个级别里至少 3 个处于严格多头排列（收 > MA7 > MA25 且 MA7 上行）。

合成级别：币安没有 2分 / 10分 / 3时 这三个周期（请求会返回 400）。 本项目用 1分→2分、5分→10分、1时→3时 在本地按「时间戳对齐 + 完整桶」合成， 并有单元测试逐字段对照币安原生K线（332 根全部一致）。

03两道缠论过滤

均线只能看出「位置」，看不出「动能是不是要衰竭了」。这两道过滤用缠论补上。

① 背驰过滤 —— 确认级别「将要出现背驰笔」

包含处理 → 分型 → 标准笔（顶底之间至少 5 根K线）→ MACD 红柱面积对比。 当前这一笔还没走完，但价格已越过前一同向笔的极值、而累计 MACD 面积反而更小 → 判定动能衰竭，拦下该信号。

实测（60 标的 / 24 小时）：15分 处于该状态的时间只占 2.76%，却拦掉了 17.9% 的信号 —— 信号恰好高度聚集在顶部区域（约 6.5 倍富集）。

② 回踩成笔链 —— 确定「笔延续级别」

只让最小级别成笔的回调是浅回调，撑不起大级别的延续。 要算作 30分 笔延续，必须让 5分、10分、15分全部成笔 —— 即从基准级别到确认级别之间（不含确认级别）的所有级别。

级别组合必须全部成笔回测保留率
5m>30m>3h5m / 10m / 15m50 → 8
2m>10m>1h2m / 3m / 5m43 → 17
3m>15m>2h3m / 5m / 10m47 → 10

判定：某级别的「最近一个完成的向下笔」的底，必须落在基准级别回调起点之后。
140 条基线信号里，只要求成笔保留 25.0%；再加上「链上各级别都站上 MA7」保留 17.9%。 卡住的总是紧挨确认级别的那一级（30分组卡 10分、10分组卡 5分）—— 它的笔最长、最难成。

这个条件非常严格，意味着原来 4 条信号里现在只留 1 条。这正是「跌无可跌」的含义， 但如果你偏好更多信号，面板上可以把这两道过滤逐个关掉。

报警文案

5分回踩后上穿MA7/EMA7，30分同步上穿均线，3时站稳EMA7不破
· 回踩已带动 5分/10分/15分 全部成笔（笔延续至 15分）
· 4个级别多头排列 · [预警(未收盘)]

04数据通道与限频

低延迟的关键在于怎么拿行情，以及别把权重打爆。

⚡ 实时价驱动

合约走 !bookTicker 全市场最优买卖价驱动K线形成，K线在边界处 1~2 秒内判定收盘。该流不消耗权重。

🔁 REST 滚动修正

滚动拉取官方K线修正真实 OHLCV。首轮回填 300 根，之后用 99 根（权重 1）合并式写入，序列随运行时间累积而不多花权重。

🚦 令牌桶 + 权重校准

用响应头 x-mbx-used-weight-1m 实时校准，按官方队列平滑请求，429/418 自动退避。

📉 稳态只用了 17%

合约权重预算 2400/分钟，实测稳态约 400/2400，留足余量应对突发。

05运行

需要 Node.js 18+（用到了内置 fetch 与 WebSocket）。无需 npm install。

git clone https://github.com/tusiyivip-source/binance-resonance-monitor.git
cd binance-resonance-monitor
node server.js                      :: 默认 = U本位合约
set MARKET=spot && node server.js    :: 切回现货

浏览器打开 http://127.0.0.1:8848。首次启动约 1~2 分钟在权重预算内渐进播种 200 标的 × 12 个原生周期的历史K线，播种期间面板已可用。

钉钉推送：⚙ 参数 → 📱 钉钉推送 → 填入机器人 Webhook 的 access_token（加签密钥可选）→ 启用 → 发送测试消息。钉钉机器人硬限 20 条/分钟，所以信号会先在聚合窗口内合并成一条再推。
为什么不能直接在这个页面上运行？ 本项目的核心是 Node 后端（维护 200 标的 × 15 级别的K线、每秒跑信号引擎、推 SSE、发钉钉）。 你现在看到的是 GitHub Pages —— 它只能托管静态文件，跑不了后端。 请按上面的命令在本机运行，得到的才是完整功能。
